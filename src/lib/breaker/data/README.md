# Codebreaker data

Generated by `node scripts/build-ngrams.mjs` (downloads the books into
`node_modules/.cache/enigma-ngrams`, then rewrites every file here). Commit the results.

| File | Contents | Size |
| --- | --- | --- |
| `ngrams-de.bin`, `ngrams-en.bin` | `"NGR1"`, 6 × float32 (floor, step of the bigram / trigram / quadgram tables), then 26² + 26³ + 26⁴ bytes of quantised log10 probabilities, `log10 p = floor + q × step`; unseen n-grams sit at `q = 0` = `log10(0.01 / total)` | 475,256 B each (≈ 90 KB gzipped) |
| `words-de.txt`, `words-en.txt` | Most frequent words of the training books (≥ 3 occurrences, 2+ letters, transliterated, A–Z, Roman numerals removed), most frequent first, one per line; German adds Enigma / military radio vocabulary (number words such as `ZWO`, `OBERKOMMANDO`, `WEHRMACHT`, `UBOOT`, `WETTERBERICHT`, …, see `MILITARY_DE` in the script) | ≈ 160 KB / 120 KB (≈ 60 / 45 KB gzipped) |
| `readable-de.txt`, `readable-en.txt` | Word list of the "Readable" plaintext view (display only, not used for scoring): FrequencyWords subtitle frequencies merged with `words-*.txt`, transliterated, A–Z, most frequent first; words of up to 3 letters only when the book lists have them too, English A and I as the only one-letter words, German military vocabulary ranked as fairly common. Built by `node scripts/build-readable-words.mjs` | ≈ 510 KB / 390 KB (≈ 230 / 190 KB gzipped) |
| `passages.ts` | 16 passages of ≈ 450 letters per language from **held-out** books (not used for the statistics or word lists) for "Try an example" and the accuracy benchmark | 24 KB |

The `.bin` / `.txt` files are imported with Vite `?url` in `breaker.ts` and fetched only when a
search starts (or when the UI calls `loadDictionary`), so they never enter the main bundle;
the browser fetches only the chosen language.

Conventions: Ä→AE, Ö→OE, Ü→UE, ß→SS, other accents stripped, letters A–Z only. In the German
n-gram training text sentence ends are written as `X` (Enigma operators' full stop). At load
time German words containing `CH` also get a `Q` variant (Kriegsmarine convention).

## Sources and licences

All texts are public-domain books from [Project Gutenberg](https://www.gutenberg.org/) (fetched
from `www.gutenberg.org` or the `gutenberg.pglaf.org` mirror). The statistics and word lists are
derived data; the passages are short excerpts of public-domain text with the Project Gutenberg
header, footer and trademark removed.

Training (n-grams and word lists):

- German: Goethe — *Die Leiden des jungen Werther* (#2407), *Die Wahlverwandtschaften* (#2403),
  *Italienische Reise* (#2404); Thomas Mann — *Buddenbrooks* (#34811); Fontane — *Effi Briest*
  (#5323); Kafka — *Der Prozess* (#69327); Schiller — *Die Räuber* (#47804); Nietzsche — *Also
  sprach Zarathustra* (#7205); Eichendorff — *Aus dem Leben eines Taugenichts* (#35312).
- English: Austen — *Pride and Prejudice* (#1342); Doyle — *The Adventures of Sherlock Holmes*
  (#1661); Dickens — *A Tale of Two Cities* (#98); Melville — *Moby Dick* (#2701); Wells — *The
  War of the Worlds* (#36); Clausewitz — *On War* (#1946); Stoker — *Dracula* (#345).

The German military vocabulary list was written for this project (no third-party source).
